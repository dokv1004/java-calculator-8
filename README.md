# java-calculator-precourse
***
## 문자열 덧셈 계산기

### 1. 기능 요구 사항
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.
1. 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
2. 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다. 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.

### 2. 요구 사항 분석
입력: 구분자와 양수로 구성된 문자열
<br>
출력: 덧셈 결과
<br>
예외처리: 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 발생
1. 숫자 관련 예외
   1. 음수가 있는 경우
2. 구분자 관련 예외
   1. 커스텀 구분자 입력 시 "//"은 있지만 "\n"이 없는 경우
   2. 커스텀 구분자가 문자가 아니라 문자열인 경우
   3. 구분자 사이에 빈 문자열이 있는 경우
   4. 구분자 앞, 뒤에 숫자가 없는 경우

### 3. 구현할 기능 목록 (필요기능)

-[ ] 사용자로부터 문자열을 입력받기
-[ ] 입력받은 문자열 검증하기
  -[ ] 입력받은 문자열이 0이거나 비어있다면 0 반환
  -[ ] 입력받은 문자열이 0이 아니고 비어있지 않다면 문자열이 유효한지 검증하기
-[ ] 검증된 문자열에서 구분자를 기준으로 숫자 추출하기
-[ ] 추출한 숫자의 합을 계산하고 반환하기
